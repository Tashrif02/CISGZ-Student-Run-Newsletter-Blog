# CISGZ Student Newsletter & Blog

A student-run digital publication platform for CISGZ. This project serves as the practical component of my TIPS (Technology Independent Project) for Grade 11.

## Project Overview
This website is designed to give students a platform to publish articles across multiple categories, including Campus Life, Updates, Athletics, Fine Arts, and Student Works. The site features a responsive, modern layout built with standard web technologies.

## Tech Stack
*   **Frontend:** HTML5, CSS3, JavaScript
*   **Hosting:** Vercel
*   **Version Control:** Git & GitHub

## Features
*   Responsive, mobile-friendly design.
*   Dynamic article grid layouts.
*   Categorized content sections.
*   Sticky navigation header.
